รอการเชื่อมต่อกับ Google Firebase Firestore

📱 วิธีให้คนอื่นเปิดใช้งานผ่านมือถือหรือคอมเครื่องอื่น

เมื่อเชื่อมต่อ Firebase สำเร็จ ข้อมูลจะบันทึกอยู่บนคลาวด์กลาง ทำให้ทุกคนเปิดใช้งานร่วมกันได้แบบ Real-time:

  • วิธีที่ 1 (แนะนำที่สุด): นำขึ้น Firebase Hosting (ฟรี) จะได้ลิงก์ เช่น https://achievement-record.web.app ส่งเข้าไลน์กลุ่มให้ทุกคนเปิดในมือถือหรือเซฟ Bookmark บนคอมได้ทันที
  • วิธีที่ 2: ส่งไฟล์ ACHIEVEMENT RECORD.html นี้ให้เครื่องอื่นเปิดได้เลย ทุกเครื่องจะดึงข้อมูลจากคลาวด์เดียวกันอัตโนมัติ

⚙️ ข้อมูลการเชื่อมต่อ GOOGLE FIREBASE (CONFIG)

(บันทึกถาวรในเครื่อง)

วางข้อความ firebaseConfig ที่คัดลอกจาก Firebase Console (Project Settings > Web App) ในช่องด้านล่าง:

📖 ยังไม่มีโปรเจกต์ Firebase? คลิกดูวิธีสร้างฟรีใน 2 นาที
  1. เข้าสู่เว็บไซต์ console.firebase.google.com แล้วล็อกอินด้วยบัญชี Google ของท่าน
  2. กดปุ่ม "Add project" (สร้างโปรเจกต์) ตั้งชื่อ เช่น achievement-record แล้วกดยืนยัน
  3. ไปที่เมนูซ้าย Build > Firestore Database แล้วกด "Create database" (เลือก Location: asia-southeast1 สิงคโปร์)
  4. ในแท็บ Rules ของ Firestore ให้เปลี่ยนเป็น allow read, write: if true; เพื่อให้ทุกคนในฝ่ายอ่านและเขียนข้อมูลได้
  5. ไปที่ไอคอนฟันเฟือง Project Settings มุมซ้ายบน เลื่อนลงมาที่หัวข้อ Your apps กดเลือกไอคอนเว็บ </> เพื่อรับโค้ด firebaseConfig แล้วนำมาวางในช่องด้านบน
