ระบบบันทึกและติดตามผลงาน/ความคืบหน้ารายการงานของ **ฝ่ายเทคโนโลยีการผลิต (PRODUCTION TECHNOLOGY)**

## 📋 โครงสร้างข้อมูลใหม่ (UPDATED DATA FIELDS)

1. **TASK NAME**: ชื่องาน / หมายเลข JIG / รายการขอซื้อ PR / รายการอุปกรณ์ ACC
2. **STATUS**:
   - 🔴 **WAIT (รอดำเนินการ)**: เช่น รออนุมัติ PR / รอ SET CODE / รอของและอุปกรณ์ / ฯลฯ
   - 🛠️ **IN PROGRESS (กำลังดำเนินการ)**: กำลังดำเนินการ / กำลัง WIRING สาย / ออกแบบ JIG / รอทดสอบระบบ
   - ✅ **DONE (สำเร็จแล้ว)**: สำเร็จแล้ว / ส่งมอบงาน / รับของเข้าสต็อกเรียบร้อย
3. **ASSIGN**: ผู้รับผิดชอบงาน (เช่น `JITTRAKAN K.`, `SUTTHIPONG M.`, `TANIN P.`)
4. **REQUEST NUMBER**: รหัสคำขอ / รหัส DRAWING / รหัสงาน (เช่น `FOR TECHNO`, `FR-J26-076`, `GM-J26-024`, `PT-25-187`)
5. **QUOTATION**: เลขที่ใบเสนอราคาอ้างอิง เช่น `26-0508`, `26-0585`, `26-0121`
6. **REQUEST NAME**: ชื่อผู้ร้องขอ (เช่น `พี่เบิ้ม`, `หัวหน้าแผนก FERRULE`, `ฝ่าย MOTOR`)
7. **REQUEST DATE**: วันที่ออกคำขอ / วันที่ร้องขอ
8. **FACTORY**: โรงงานที่รับผิดชอบ (เช่น `FACTORY 1`, `FACTORY 2`)
9. **DEPARTMENT**: แผนกที่ร้องขอ (เช่น `FERRULE`, `MOTOR`, `QC`, `FIBER`, `PRODUCTION TECHNOLOGY`)
10. **PROCESS**: กระบวนการหรือขั้นตอน (เช่น `GLUING`, `WIRING`, `ASSEMBLY`, `MACHINING`, `TESTING`)
11. **DETAIL**: รายละเอียดงานและการประสานงาน
12. **NOTE**: บันทึกความคืบหน้า สิ่งที่กำลังรอ
13. **DATE**: วันที่สำเร็จหรือวันที่บันทึกงาน

## 📎 ระบบเอกสารแนบและผลงาน (ATTACHMENTS & DELIVERABLES)

1. **ใบ PRODUCTION TECHNOLOGY DEPARTMENT JOB REQUEST (ไฟล์ PDF)**:
   - สามารถอัปโหลดไฟล์ใบคำขอ `.PDF` เข้าสู่ระบบได้โดยตรง
   - มีปุ่ม **"📄 JOB REQUEST (PDF)"** ให้คลิกเพื่อเปิดดูเอกสาร PDF แบบเต็มหน้าต่างได้ทันที
2. **โฟลเดอร์ผลงาน (WORK FOLDER ATTACHMENT / ONEDRIVE)**:
   - มีปุ่ม **"📁 เลือกแนบโฟลเดอร์จากเครื่อง"** สามารถคลิกเลือกโฟลเดอร์งานหรือ DRAWING จากเครื่องได้โดยตรง
   - มีระบบตรวจนับจำนวนไฟล์และขนาดรวมของโฟลเดอร์ พร้อมปุ่ม **"📑 ดูรายชื่อไฟล์"** แสดงรายการไฟล์ทั้งหมดในโฟลเดอร์พร้อมไอคอนแยกตามประเภทไฟล์ (.DWG, .STEP, .PDF, .XLSX, ฯลฯ)
   - รองรับการระบุ Path ในเครื่อง หรือวางลิงก์ OneDrive / SharePoint พร้อมปุ่ม **"📋 คัดลอก PATH"** และ **"🌐 เปิดใน ONEDRIVE"**
3. **รูปภาพผลงาน / ชิ้นงาน / DRAWING (IMAGE & PDF ATTACHMENT)**:
   - แนบไฟล์ภาพถ่ายผลงานหน้างาน หรือแบบงาน DRAWING ที่เป็นไฟล์ **PDF** หรือรูปภาพทุกนามสกุล (.JPG, .PNG, .WEBP, .PDF, ฯลฯ)
   - **ไม่จำกัดขนาดไฟล์ภาพและเอกสาร** เพื่อให้สามารถแนบแบบ Drawing หรือภาพความละเอียดสูงได้เต็มที่
   - มีปุ่ม **"📄 DRAWING (PDF)"** หรือ **"🖼️ DRAWING (IMG)"** ในการ์ดและตาราง สามารถคลิกเปิดดูไฟล์ DRAWING ได้ทันที พร้อมพรีวิวแยกหมวดหมู่ชัดเจน
